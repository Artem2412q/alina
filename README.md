# Приглашение для Алины

Готовый статический сайт для телефона и компьютера. Сборка и установка пакетов не нужны.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Загрузите index.html, style.css, app.js, roses.png и .nojekyll в корень репозитория. Загружайте файлы, а не сам ZIP.
3. В настройках репозитория откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку main и папку / (root), затем сохраните.
5. Когда публикация завершится, GitHub покажет ссылку на сайт.

## Отправка выбора на почту

Получатель: artemcepko69@gmail.com. Используется FormSubmit.
После публикации выполните пробную отправку с сайта и подтвердите подключение по письму от FormSubmit. Проверьте также папку «Спам». При смене адреса сайта может потребоваться повторное подтверждение.
Реальная доставка письма пока не проверена. Перед отправкой ссылки Алине убедитесь, что тестовое письмо пришло.
Если автоматическая отправка не удалась, сайт предложит отправить готовое письмо через почтовое приложение; там нужно нажать «Отправить» самостоятельно.

## Содержание

Даты: 2, 4 и 5 октября 2026 года. Кухни: итальянская, японская, грузинская, европейская, бургеры, «Доверюсь тебе». Время: предложенные варианты или своё, по Москве.

Файлы используют относительные пути, поэтому сайт работает и в подпапке GitHub Pages.
Google Fonts и отправка через FormSubmit требуют интернета; при недоступности шрифтов используются системные.
